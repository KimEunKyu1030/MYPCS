PIN 번호 · 코드와 함께 알려줘야 접속이 허용됩니다
대기 중
로컬 도우미 미확인
참고 — 방 코드와 PIN을 모두 아는 사람만 접속이 허용됩니다. PIN이 틀리면 즉시 연결이 차단됩니다. 화면 공유를 시작하면 자동으로 localhost:8765의 로컬 도우미(host-helper)에 연결을 시도합니다. 화면 공유를 브라우저 자체 버튼으로 중지하거나 "세션 완전히 종료"를 누르면 방 코드·PIN·데이터 채널이 즉시 전부 무효화됩니다. 그냥 브라우저의 "공유 중지"만 누르고 탭은 열어두는 경우에도 이제 자동으로 전체 연결이 끊깁니다.
